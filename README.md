# Mi Sitio CI/CD

Sitio web estático desarrollado como práctica individual del Laboratorio 6.1.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- GitHub Actions
- Amazon S3
- Amazon CloudFront

## Despliegue

El sitio se despliega automáticamente en AWS S3 cada vez que se realiza un `push` a la rama `main`.

También se utiliza CloudFront como CDN con invalidación automática de caché.
